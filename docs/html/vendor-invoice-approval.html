Vendor invoice approval, photos and Excel

Vendor invoices are read (PDF or photos), sent for approval, and booked as a goods receipt only once approved. Import Data takes Excel and has a new layout. Decision: ADR 0051. Branch: feature/import-data-redesign (on top of feature/vendor-invoice-import).

Flow

Staff (inventory.stock.receive)
  Inventory → Import Vendor Invoice → PDF or photos → review → [Send 24 lines for approval]
  → "Sent for approval as VIN-2026-000001"          approvers at that location get a notification

Manager / admin (inventory.invoices.approve)
  Approval queue → Pending → Bonesca · VIN-2026-000001 · 108666 · 24 lines (3 new) · € 5.739,80
    correct lines → [Approve and book]  → new items created, GR-2026-… booked, sender notified
                  → [Reject] + reason   → sender notified with the reason

API

RouteWhoNotes

POST /inventory/invoices/:id/rejectinventory.invoices.approve{ reason }

POST /inventory/receipts/import is gone. Photos and scanned PDFs are read on the device (OCR); only the reviewed lines are sent, marked source: scan.

Import Data

  • Header "Bring your existing data in" with three steps; one tile per kind (icon, description, CSV · Excel).
  • Vendor invoice tile (PDF · Photos) leads to the upload, with a link to the approval queue.
  • .xlsx read on the device: the sheet named like the kind, else the first; numbers as Excel stored them.
  • Required columns are highlighted; .xls and other files are refused with a clear message.

Manual

  • As staff: Import Vendor Invoice → 108666.pdf → Send → done screen with VIN number; stock unchanged.
  • As manager: bell shows "invoice submitted" → Approval queue → open → change a quantity → Approve → receipt number shown; stock up.
  • Take two photos of a paper invoice → lines read, "check every line" hint shown.
  • Import Data → Products → upload an .xlsx → preview shows the rows.
