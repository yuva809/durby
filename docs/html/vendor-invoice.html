Vendor invoice import (PDF)

A supplier's invoice or order confirmation as a PDF becomes one goods receipt; products not in Durby yet are created with it. Also: the till's roles only where there is a till. Decision: ADR 0049. Branch: feature/vendor-invoice-import (on top of feature/asiamight-inventory).

Flow

Inventory → [Import Vendor Invoice]      (or Import Data → Vendor invoice (PDF))
  1  Choose PDF  →  read on this device
  2  Review
     Supplier [Bonesca]   Note [Order 108666 · 10-11-2026]   Warehouse [Main ▾]
     Unit of new items [piece ▾]   Category of new items [Frozen fish ▾]
     ☑ 1103-002 Bigi Mama African Catfish …   [Catfish 4kg ▾]   50   11.00   € 550,00
     ☑ 1971-002 OD Yellow Croakers …          [New item ▾] New   30   41.50   € 1.245,00
     …
     Receipt total: € 5.739,80   ✓ Matches the invoice total of € 5.739,80
                                         [Choose another PDF] [Import 24 lines]
  3  Goods receipt GR-2026-… booked with 24 lines

How the PDF is read

PartRule
Rowstext pieces on the same baseline (±3 pt), left to right; pages top to bottom; at most 20 pages
Item line[code with a digit] description quantity [€] price [€] [VAT %] [€] total — at the end of the row
Amounts1.245,00 and 1,245.00 alike; each line checked: quantity × price = total (± 1 cent)
Headernumber from "Order number / Invoice no. / Rechnungsnummer …", first dd-mm-yyyy date, supplier from the footer e-mail domain
Grand totallast "Total" row that isn't net, excluding VAT or a weight
MatchingSKU = supplier code, then exact name (case and spaces aside); else New (SKU = supplier code)

Bonesca order confirmation 108666 (the PDF from the request) reads 24 lines, every line checks, and they add up to exactly € 5.739,80. Its supplier footer is an image, so the supplier is typed once.

API: POST /api/v1/inventory/receipts/import — lines { itemId, quantity, unitCost } or { newItem: { name, sku, unit, categoryId }, quantity, unitCost }; one transaction; new items need inventory.items.edit.

Roles

Waiter, Cashier, Kitchen, Bar (need pos) and Host (needs reservations) are no longer offered to an organization without them. AsiaMight's pickers: Owner, Admin, Manager, Staff, Branch, Warehouse, Driver.
