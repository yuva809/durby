Branch stock requests

Branches restock from the main warehouse: request → approval → picking → driver → receipt, each person seeing only their part. Decision: ADR 0045. Spec: docs/modules/orders.md → Branch requests. Branch: feature/branch-requests.

Flow

Branch ──Request Stock (SRQ-2026-000047)──▶ Owner/Admin: Approve (quantities may change) / Reject
                                                │ becomes TRF-2026-000047
Warehouse (Lager): Picking → Pick (short allowed) → Packed  [+ driver]   stock: Main ▶ In transit
Driver: My Deliveries → Picked up → Delivered
Branch: Stock Requests → Confirm receipt (≤ packed)                      stock: In transit ▶ Branch, rest = shortage

Roles and menus

RoleSidebar (operations layout)Key points
Owner / AdminEverything, incl. Stock Requests (approve)Only they hold orders.requests.approve
BranchInventory (own stock), Request Stock, Stock Requests, Branches, Settings, FeedbackLimited to their branch location; sees main warehouse quantities only in Request Stock
Warehouse (Lager)Inventory, Order History, Stock Requests, Picking, Branches, Delivery Tracking, Import Data, FeedbackPicks, packs, assigns drivers, books goods in
DriverMy Deliveries, Settings, FeedbackSees only deliveries assigned to them
The three roles exist in every organization but only show where the organization has the orders module, so app.durby.tech restaurants never see them. Onboard: Manage Staff → Add staff → role Branch / Warehouse (Lager) / Driver → for a Branch pick its location.

Stock

  • Packed: one transfer document from the source warehouse to In transit (created automatically, one per organization) for the picked quantities, at average cost. Refused when stock would go below zero, unless the location allows negative stock.
  • Received: a transfer from In transit to the branch's warehouse for what arrived, and an adjustment out of In transit for the rest (shortage).
  • All documents carry the request (source_request_id) and show in Inventory → Documents.
